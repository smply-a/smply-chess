# Smply Chess Platform

Meine version einer chess website mit meiner vorstellung eines guten UI und mit möglichst viel
eigenen Ideen.
Ich versuche auch so gut es geht auf fremde libs zu vertrauen, um Probleme und die Lösungen in der Tiefe zu Verstehen.

In zukunft soll man hier multiplayer und gegen meine eigene Chess-Engine spielen können.
